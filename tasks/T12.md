Edit `class Snapshot` in `lib/session.dart`, exactly like `breakLabel` was added (constructor, field with doc comment, `==`, `hashCode`, `toJson`, `fromJson`, with defaults for missing JSON keys so old snapshots still load). New fields:
- `final int setupMs;` default `120000` (Setup length, ms).
- `final int packMs;` default `60000` (Pack length, ms).
- `final String stage;` default `''`. One of `''` (not in the loop), `'setup'`, `'talk'`, `'qa'`, `'pack'`, `'draw'`.
- `final List<int> done;` default `const []`. Indexes into `groups` of presenters that have finished; they are hidden everywhere. Compare it with the same list helper `groups` already uses (`_listEquals`) and hash it with `Object.hashAll(done)`. In `toJson` write it as a plain list; in `fromJson` read `(json['done'] as List?)?.cast<int>() ?? const []`.

Tests in `test/session_test.dart` (at least 4 new): full roundtrip with all four fields set; a JSON without the four keys loads the defaults; two snapshots differing only in `done` are not equal and the same lists are equal; `stage` roundtrips.
