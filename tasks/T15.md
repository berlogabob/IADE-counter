```dart
/// The wheel's slices: names of the presenters not in [done] (original order) and
/// the slice index of [winner] (an index into [names]); winnerSlot is -1 if the winner is in [done] or out of range.
({List<String> labels, int winnerSlot}) wheelPool(List<String> names, List<int> done, int winner);
```
Test it in `test/loop_test.dart` (at least 3 tests: nothing done; some done before the winner so the slot shifts; winner done or out of range gives -1).
